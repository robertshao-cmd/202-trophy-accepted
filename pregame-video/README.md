# Pregame video pipeline

1. Review and approve `01-pregame/script.md`.
2. Capture the real game UI as `01-pregame/assets/ui-home.png`.
3. Generate the 12-second base video with Seedance 2.0 using `01-pregame/seedance-prompt.md`.
4. Add Traditional Chinese cards and sound mix with ffmpeg.
5. Verify the final MP4 at 16:9, 720p, 24fps.

The generated base video must not include real employee headshots or model-generated Chinese text.
